# 证据扰动协议

三名标注者独立选择 A1 相关图像区域和文本关键词，至少两人一致形成图像证据 E_I 与文本证据 E_T；无多数一致时复核。A1相关图像遮挡以当前图像RGB均值填充 E_I，随机对照以种子42将同形状、同面积掩码平移到非证据位置。文本定向扰动删除 E_T，随机对照从非 E_T 词中以种子42删除相同数量。图文错配在相同语言、相同标签测试样本内进行无原位重排。最小文本反事实由人工只修改 E_T，并经两名复核者共同通过。

错配和反事实不重新赋予类别标签，也不计算 Acc 或 wF1，只考察学生模型对原预测类别的归一化概率变化。设原完整输入预测类别为 ĉ：

`Suff = p(ĉ|I,T) - p(ĉ|E_I,E_T)`

`Comp = p(ĉ|I,T) - p(ĉ|I\E_I,T\E_T)`

概率在两个候选类别之间归一化。本仓库不实现图像遮挡、模型前向推理或反事实自动生成。
